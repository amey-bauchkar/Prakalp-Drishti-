# 🌧️ Janhavi's Workspace: VARSHA-SPEED
### IMD Monsoon Rainfall Pattern & Seasonal Working-Window Contraction

## 📌 Module Responsibilities:
- Quantifies lost construction days per millimeter of excess rainfall using 2005–2025 IMD rainfall anomalies.
- Calculates state-level effective working months for roads, highways, and earthworks.

## 🚀 How to Build & Extend:
1. Write core analytical logic in `modules/janhavi/service.py`.
2. Expose endpoints in `modules/janhavi/router.py` (prefix: `/api/janhavi`).
3. Build the frontend view in `frontend/janhavi/index.jsx`.
4. Run tests in `tests/`.
