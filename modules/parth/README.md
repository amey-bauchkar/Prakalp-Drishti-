# 📈 Parth's Workspace: ARTHA-NETRA
### PSU Contractor Financial Health, Debt-to-Equity & Stock Market Risk

## 📌 Module Responsibilities:
- Analyzes executing PSU debt leverage ratios (Debt/Equity), Altman Z-scores, and equity market drawdowns.
- Links financial stress to future cost overrun claims and construction halts.

## 🚀 How to Build & Extend:
1. Write core analytical logic in `modules/parth/service.py`.
2. Expose endpoints in `modules/parth/router.py` (prefix: `/api/parth`).
3. Build the frontend view in `frontend/parth/index.jsx`.
4. Run tests in `tests/`.
