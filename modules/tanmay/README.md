# 🛡️ Tanmay's Workspace: SATYA-KAVACH
### 20% CCEA Cabinet Approval Threshold Anti-Gaming & Contractor Claim Audit

## 📌 Module Responsibilities:
- Analyzes budget revision clustering just below the mandatory 20% CCEA Cabinet approval threshold.
- Detects deliberate contractor under-reporting and strategic margin gaming.

## 🚀 How to Build & Extend:
1. Write core analytical logic in `modules/tanmay/service.py`.
2. Expose new endpoints in `modules/tanmay/router.py` (prefix: `/api/tanmay`).
3. Build the frontend dashboard in `frontend/tanmay/index.jsx`.
4. Run tests in `tests/`.
